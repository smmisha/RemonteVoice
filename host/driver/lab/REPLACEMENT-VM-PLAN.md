## Разрешаемые действия при согласии пользователя

1. Создать и запустить только указанную VM, установить Windows на её новый пустой виртуальный диск. Не форматировать физические накопители и не подключать их напрямую к гостю.
2. Сеть, передача микрофона/камеры и общий буфер обмена отключены. Microsoft Account, покупки, активация сторонними средствами и автоматический вход исключены. Пароль локальной тестовой учётной записи пользователь задаёт сам при необходимости.
3. При необходимости установить VMware Tools только внутри гостя из уже имеющегося официального локального носителя VMware. Если такого носителя нет, не загружать новый без отдельного решения.
4. Сохранить чистый снимок с выключенной тестовой подписью до изменений драйвера. Подтвердить идентичность VM, установленную Windows и возможность восстановления снимка.
5. Перенести проверенный пакет `host/build/driver-pair-010` и ранее проверенный подписанный лабораторный драйвер в гостя. Повторно сверить их хеши. Передавать только публичный тестовый сертификат, без закрытого ключа.
6. Только в госте доверить публичный сертификат, включить тестовый режим загрузки и перезагрузить VM; установить собственный драйвер. Основную Windows, её доверие сертификатам, службы, драйверы и параметры защиты не менять.
7. Разместить broker/client в отдельной защищённой папке гостя и установить её ACL по ранее согласованному плану. Проверить настоящую связанную пару повышенного и ограниченного токенов; не ослаблять проверку участников IPC.
8. Проверить выключенный микрофон при подключении, синтетический PCM в обоих направлениях, тишину после выключения, разрыв/повторное подключение и возврат ролей устройств/mute внутри гостя. Физический микрофон ноутбука и микрофон телефона не включать и не записывать.
9. Сохранить только ограниченные отчёты с параметрами и результатами. Завершить тестовые процессы, удалить точный тестовый драйвер/пакет из гостя, восстановить чистый снимок, подтвердить исходное состояние гостя и выключить VM. Саму новую VM и исходный ISO сохранить.
