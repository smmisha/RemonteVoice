# iReSign — рабочее название

## Переименование 12 ноября 2026

Рабочее название подписчика: LocalSign → (ошибочно Remonte) → **iReSign**. Remonte — название основного приложения RemonteVoice, к подписчику не относится. Идентификатор приложения — `dev.remotevoice.iresign`, пространство Windows Credential Manager — `dev.remotevoice.iresign.v1`. Записи прежних прототипов LocalSign (`dev.remotevoice.localsign.v1`) и Remonte (`dev.remotevoice.remonte.v1`) этой сборкой не читаются; при необходимости их можно удалить в Windows Credential Manager. Старые значения автозапуска `LocalSign` и `Remonte` удаляются при следующем включении или выключении автозапуска.

## Anisette 12 ноября 2026

Локальный Anisette v3 поднят в Ubuntu WSL (Docker на этом ноутбуке не установлен) и доступен iReSign по `http://127.0.0.1:6969`. Проверка `--check-anisette` выполнила провижининг: сервис отвечает и готов к входу. Автозапуск при входе в Windows добавлен через папку Startup. Подробности, управление и лицензионные ограничения — [ANISETTE.md](ANISETTE.md). В репозитории Anisette-сервера лицензия не заявлена, поэтому это локальная личная установка, а не компонент для распространения. Отчёт: [anisette-local-verification.json](../.harness/evidence/signing-utility/anisette-local-verification.json).

## Автопродление 12 ноября 2026

Добавлен прототип автоматического продления для явно выбранных приложений. Приложение хранит одобренную копию IPA и SHA-256, проверяет срок профиля через Apple, доступность iPhone по USB и переустанавливает IPA заранее. Планировщик работает, пока запущен iReSign; автозапуск при входе в Windows включается отдельно.

Сессию Apple Account можно явно сохранить в Windows Credential Manager (только техническая сессия, не пароль), чтобы продление работало после перезапуска. Продление использует тот же журнал эффектов, что и ручная установка: неизвестный результат блокирует повтор до проверки на iPhone.

Проверено локально: 39 Rust-тестов, Clippy с `-D warnings`, TypeScript/Vite production build, встроенный frontend, разбор RemoteVoice IPA, запись/чтение/очистка фиктивной сессии в реальном Windows Credential Manager, провижининг локального Anisette и запуск окна приложения. Реальные вход, подпись, установка и цикл продления не выполнялись; рабочий Apple Account по-прежнему отсутствует.

## Исправления надёжности 23 октября 2026

Выбранный IPA копируется в контролируемый staging, анализ и SHA-256 относятся к одним байтам; Windows handle удерживает запрет записи/замены до завершения подписи. По исходникам закреплённого isideload 0.4.4 библиотека читает IPA, а подписывает извлечённую копию приложения; нативная установка этого варианта ещё не проверена.

Discovery ограничен 20 секундами, ожидание opaque install future — 600 секундами. Таймаут не доказывает отмену установки на устройстве. Журнал сохраняет effect ID/hash/target/phase и блокирует слепой повтор. После ручной проверки результата карточка позволяет отдельно разрешить новую попытку для точной операции; кнопка не запускает установку и не объявляет прежнюю успешной. Повреждённый журнал остаётся fail-closed и требует восстановления.

На 23 октября 2026: 20 Rust-тестов и TypeScript/Vite build прошли локально. Реальная подпись/установка, собственный Anisette и Store остаются открытыми. Подробный статус — [STABILITY.md](../STABILITY.md).


Windows-утилита для личной подписи и установки IPA на iPhone. Возможная публикация в Microsoft Store — после работающего прототипа и проверки требований магазина.

Созданы исходники Windows-прототипа 0.1 на основе потоков iloader/isideload, отдельный интерфейс, автопродление и сценарий сборки. Сборка EXE, 39 компонентных тестов, Clippy и запуск диагностики без Apple Account прошли на этом ноутбуке.

Готовая локальная сборка: `preview/iReSign.exe`. Это debug-прототип; установщик, публикация и PE-подпись издателя не подготовлены. Инструкции: [BUILD.md](app/BUILD.md), описание данных: [PRIVACY.md](app/PRIVACY.md).

IPA RemoteVoice прочитан, его bundle ID и SHA-256 проверены. Защищённое хранилище доступно. Локальный Anisette поднят и прошёл провижининг. На момент последней диагностики список iPhone по USB был пуст. Вход, реальная подпись/установка и реальный цикл автопродления ещё не проверены и не завершены.

Первый результат: наша сборка обнаруживает iPhone по USB, подписывает выбранный IPA через Apple Account пользователя и подтверждает установку на устройстве. Первый проверочный IPA — RemoteVoice.

Порядок первого реального запуска: [FIRST-RUN.md](FIRST-RUN.md). Отчёт проверок текущей сборки: [iresign-verification.json](../.harness/evidence/signing-utility/iresign-verification.json).
