# iReSign: первый реальный запуск

Это порядок действий для первой проверки на живом iPhone. Пока он не выполнен,
iReSign остаётся прототипом: вход, подпись, установка и автопродление не
подтверждены.

## Что нужно заранее

1. Anisette-сервис. На этом ноутбуке уже поднят локальный Anisette v3 по
   `http://127.0.0.1:6969`; управление и ограничения — [ANISETTE.md](ANISETTE.md).
   Удалённый сервис должен быть HTTPS и не содержать логина, query или fragment.
2. Рабочий Apple Account, который пользователь вводит сам. Пароль и 2FA не
   сохраняются; по желанию можно сохранить только техническую сессию в Windows
   Credential Manager.
3. iPhone по USB, разблокированный и доверяющий этому компьютеру.
4. iTunes / Apple Mobile Device Support, если `--diagnostics` не видит устройство.

## Шаги

1. Проверить окружение:
   ```powershell
   .\signer\preview\iReSign.exe --check-anisette http://127.0.0.1:6969
   .\signer\preview\iReSign.exe --diagnostics
   ```
   Anisette должен вернуть `{"provisioned":true,"reachable":true}`. Для iPhone
   ожидается `"protectedStorage": true` и подключённое устройство в `devices`.
   Если устройств нет, проверить USB, разблокировку и доверие компьютеру.
2. Запустить `iReSign.exe`, выбрать iPhone и IPA RemoteVoice. Убедиться, что
   показаны имя, bundle ID и SHA-256.
3. Ввести адрес Anisette (`http://127.0.0.1:6969` для локального), Apple Account и
   пароль. Включить «Сохранить сессию для автопродления», если продление должно
   работать после перезапуска. Подтвердить 2FA.
4. Нажать «Подписать и установить». Дождаться завершения. Проверить запуск
   RemoteVoice на iPhone и доверие профилю разработчика.
5. После успешной установки добавить приложение в автопродление. Проверить, что
   в карточке появился срок профиля и результат «Успешно».
6. Проверить план и сессию:
   ```powershell
   .\signer\preview\iReSign.exe --check-renewal
   .\signer\preview\iReSign.exe --check-session
   ```
   `--check-renewal` печатает срок профиля и результат, но не UDID.
7. Для отдельной проверки цикла нажать «Продлить сейчас» или дождаться
   планировщика. После успеха срок профиля должен обновиться; повторная
   установка не должна запускаться каждые 15 минут.

## Что зафиксировать

- Скриншот карточки приложения в iReSign со сроком профиля и результатом.
- Вывод `--check-renewal` до и после продления.
- Подтверждение запуска RemoteVoice на iPhone.
- Время и результат цикла; если была ошибка — её фиксированный код в интерфейсе.

## Границы

- Продление работает, пока запущен iReSign и iPhone доступен по USB. Автозапуск
  при входе в Windows включает фоновый режим, но не заменяет Anisette и сессию.
- Неизвестный результат установки блокирует повтор до проверки на iPhone.
- Бесплатный профиль Apple остаётся семидневным.
- Пароль не сохраняется. Техническая сессия может быть отозвана Apple; тогда
  нужен новый вход.
