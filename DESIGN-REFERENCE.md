# Единый стиль RemoteVoice: эталон Android

Обязательное требование REQ-039 от 24 октября 2026: оформление Windows выводится из интерфейса телефона. Различия компоновки допустимы для размеров экрана и платформенных функций; цвета, скругления, иерархия, семантика кнопок и состояний согласованы.

Проверенный снимок: `.harness/evidence/design/android025-reference-top.png`, Android 0.1.25, подключённый сеанс, микрофон выключен. Ради снимка штатно скрыт защищённый просмотр экрана, аудиосоединение не отключалось. Реальные кадры ноутбука не сохранялись. Screenshot локальный, не включён в Git.

Эталон из изображения и MainActivity.java:

- Фон #101815, карточки #1B2922, вторичные кнопки #24392E, акцент #80E8BA, текст #EBF5F0, вторичный текст #A4B9AE, граница #365144. Эти цвета уже совпадают с desktop_ui.py.
- Карточки: радиус20dp, рамка1dp, внутренний отступ20dp, промежуток16dp; статус отдельным спокойным блоком.
- Кнопки: радиус16dp, минимальная высота52dp, текст16sp; акцент выделяет основное действие, отключение остаётся доступным в отдельной нижней области.
- Заголовок28sp bold, заголовок карточки18sp bold, статус19sp bold, пояснения13-15sp. На Windows сохранить визуальные отношения с учётом DPI, а не копировать физические пиксели.

Видимые расхождения: текущие ttk-карточки и кнопки Windows прямоугольные, основные тексты и контролы плотнее, статус устроен иначе. Одного совпадения палитры недостаточно для REQ-039.
