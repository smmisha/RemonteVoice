# LocalSign — рабочее название

## Исправления надёжности 23 октября 2026

Выбранный IPA копируется в контролируемый staging, анализ и SHA-256 относятся к одним байтам; Windows handle удерживает запрет записи/замены до завершения подписи. По исходникам закреплённого isideload 0.4.4 библиотека читает IPA, а подписывает извлечённую копию приложения; нативная установка этого варианта ещё не проверена.

Discovery ограничен 20 секундами, ожидание opaque install future — 600 секундами. Таймаут не доказывает отмену установки на устройстве. Журнал сохраняет effect ID/hash/target/phase и блокирует слепой повтор. После ручной проверки результата карточка позволяет отдельно разрешить новую попытку для точной операции; кнопка не запускает установку и не объявляет прежнюю успешной. Повреждённый журнал остаётся fail-closed и требует восстановления.

20 Rust-тестов и TypeScript/Vite build прошли локально. Реальная подпись/установка, собственный Anisette, автопродление и Store остаются открытыми. Подробный статус — [STABILITY.md](../STABILITY.md).


Windows-утилита для личной подписи и установки IPA на iPhone. Возможная публикация в Microsoft Store — после работающего прототипа и проверки требований магазина.

Созданы исходники Windows-прототипа 0.1 на основе потоков iloader/isideload, отдельный интерфейс и сценарий сборки. Сборка EXE, шесть компонентных тестов, Clippy и запуск диагностики без Apple Account прошли на этом ноутбуке.

Готовая локальная сборка: `preview/LocalSign.exe`. Это debug-прототип; установщик, публикация и PE-подпись издателя не подготовлены. Инструкции: [BUILD.md](app/BUILD.md), описание данных: [PRIVACY.md](app/PRIVACY.md).

IPA RemoteVoice прочитан, его bundle ID и SHA-256 проверены. Защищённое хранилище доступно. На момент последней диагностики список iPhone по USB был пуст. Вход, реальная подпись/установка, работа собственного Anisette и автопродление ещё не проверены и не завершены.

Первый результат: наша сборка обнаруживает iPhone по USB, подписывает выбранный IPA через Apple Account пользователя и подтверждает установку на устройстве. Первый проверочный IPA — RemoteVoice.

Подробности: [план первой версии](PLAN.md). Проверенная исходная версия и результаты чтения кода: [реестр исследования](research/upstream.json).
