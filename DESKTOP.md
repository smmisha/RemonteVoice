# Windows-интерфейс RemoteVoice 0.1.5

Текущий результат Windows 0.1.7 / Android 0.1.8 — [BACKEND-RECHECK.md](BACKEND-RECHECK.md). Ниже сохранён предыдущий срез; он не заменяет проверки новой сборки.

23 октября 2026. Единый стиль с Android, существующий Tkinter/ttk, без новых runtime-зависимостей.

## Изменения

- Тёмный фон, мятный акцент и светлый текст соответствуют Android-клиенту. Общие цвета, шрифты, размеры и состояния собраны в `host/remotevoice/desktop_ui.py`.
- «Подключение» содержит сопряжение, QR-код, локальный адрес и разрешение просмотра экрана. Аудиоканалы и устройства возврата находятся во вкладке «Аудиоустройства».
- Статус и кнопки возврата, остановки и подключения остаются вне прокручиваемой области. Окно изменяет размер; на узкой ширине колонки перестраиваются.
- Устройства показываются под читаемыми названиями. Их точные ID по-прежнему используются для выбора, сохранения и восстановления. Дубликаты названий различаются.
- Русские подписи и сообщения согласованы с кнопкой «Начать подключение». Причина ошибки микшера сохраняется в статусе.
- Исправлено запоздавшее событие `audio_active`: после восстановления устройств или остановки оно не меняет статус на «Телефон подключён».

## Проверено

- 265 тестов Host и compileall прошли. Включены сохранение выбора по ID, совпадающие имена, отключённые контролы и позднее событие аудио.
- Настоящие Tk-виджеты проверены на синтетических данных: QR, сопряжённое состояние, активный сеанс, длинная ошибка, длинное имя устройства, окно от 800 × 600 и увеличенный Tk scaling около 2,0. Это проверка масштаба Tk, не сертификация всех мониторов Windows.
- EXE собран PyInstaller в формате папки приложения. Независимый helper проверен из пакета. Обычный разрыв, аварийный разрыв транспорта и авария Host проверены на реальных устройствах Windows; отдельная проба проверяет сохранение исходного mute=True.
- Итоговый снимок работающего приложения — `.harness/evidence/desktop-ui/live-connection.png`; журналы, хэши и числовые результаты — рядом. Проверочные окна используют вымышленные данные и не открывают аудиоустройства.

## Использование

Локальный пакет: `host/build/RemoteVoice-Windows-0.1.5-local.zip`. Распаковать папку целиком и запустить `RemoteVoice/RemoteVoice.exe`. Каталог `_internal` необходим. Должен работать ранее установленный Voicemeeter Banana. Android остаётся версии 0.1.4; протокол не менялся.

Минутная проверка телефона с блокировкой была принята пользователем на предыдущем Windows EXE 0.1.4. Эта приёмка сохраняется как история; для 0.1.5 выполнены указанные локальные и нативные проверки. Длительные сеансы, глубокий сон Android, установки/обновления и публичная подпись остаются отдельными задачами.
